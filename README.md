# German Learning (Currently B1, sprinting towards B2)

**Author:** Krishna Chaitanya Kidambi

## Description

This repository records my progress in learning German. It holds four Excel workbooks that I build and update as I study: a vocabulary workbook with more than 10,000 words sorted by der, die, das and other words, a grammar workbook with one sheet per topic and examples, a Ready Reckoner of class words from A to Z, and a Career German workbook with finance and office terms. Every sheet also has a CSV copy for reading on GitHub, and a daily journal records each topic, exercise and speaking practice. The workbooks and CSVs are updated periodically as new words and rules come in, so the repository keeps growing into a complete reference for the language. Alongside the formal classes, I study intensively by myself with videos, Claude and speaking exercises, and I am optimistic about reaching B2 within the next 3 to 5 months.

## Files and folders

- `csv` — CSV copies of every workbook sheet in UTF-8, for easy reading and search; sheets with more than 300 rows come in numbered parts of 300 rows for the GitHub table view.
- `csv/Finance Related Vocab_Finance related Vocab.csv` — Career German terms for finance, accounting, SAP, office and interview words, with meanings, opposites and three examples per term.
- `csv/German_Ready_Reckoner_<letter>.csv` — Class words from the Ready Reckoner workbook, one file per letter from A to Z, plus Ä, Ö and Ü.
- `Finance Related Vocab.xlsx` — Career German workbook with finance, accounting, SAP, office and interview terms.
- `German Grammar Rules.xlsx` — Grammar workbook with a table of contents and one sheet per topic, from articles, tenses, prepositions, connectors, adverbs and interjections to word endings, prefix verbs, reflexive verbs, homonyms, homophones and paronyms, and word sets for body parts, diseases, food, animals and plants.
- `German_Ready_Reckoner.xlsx` — Ready Reckoner workbook with class words sorted from A to Z, one sheet per letter, with a search sheet.
- `German_Vocabulary.xlsx` — Vocabulary workbook sorted by der, die, das and other words, with a search sheet, a key and a guide for adding words.
- `JOURNAL.md` — Daily log of the topics learned and practiced, one dated entry per day.

## About the CSV parts

GitHub shows a CSV file as a readable table up to a certain file size, so every sheet with more than 300 rows is split into numbered parts of 300 rows, and each part repeats the header row. The complete sheets are in the Excel workbooks, which download in one piece with the "Download raw file" button on each workbook's page. The parts of a sheet can also be joined in number order, with the header row kept once, to rebuild the full sheet.
